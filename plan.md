# Traveler 
This is an Application suitable for android and ios.

## Description: This is a travel type application to plan, record, and handle for trips plan.

### Feature:
1. Able to create different topic for different trips. Each trips should be isolated and had the same features.
2. In trip: allow to enter the planning or attach the planning file(text), visualize the plan with time table
3. For different events in plan, allow user to key in and record the experience, such as feeling or book-keeping for food and devide for each other
4. Allow to add event for plan in middle, so user can decide wat to do actually on time
5. Currency converter, create a currency converter for different plan based on the target country. Convert to MYR by default, allow user to change convert direction as well(default: key in x CNY -> convert to y MYR, allow user to change key in x MYR -> convert to y CNY)
6. Allow to attach files such as tickets, documentation so user can save into here and open quickly
